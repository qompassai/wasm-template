# WebAssembly quickstart

- Spec: https://webassembly.org/ ; text format: https://webassembly.github.io/spec/core/text/
- Toolchain: wabt (`wat2wasm`, `wasm-objdump`) — https://github.com/WebAssembly/wabt
- From Rust: `cargo build --target wasm32-unknown-unknown`
- From C/C++: Emscripten (https://emscripten.org/)
- Run: node, wasmtime (https://wasmtime.dev/), or a browser.
